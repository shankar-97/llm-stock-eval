# web

Vite + React + TypeScript dashboard: Verdict, Scorecard, Experiments, and
Cost/traces screens at launch; Screeners after. Tailwind with shadcn/ui,
TanStack Query, Recharts. Filters live in URL params so any view is a
shareable link. Types are generated from the API's OpenAPI spec.

The Scorecard is the screen to open in an interview — it answers "does it
work?" before anyone asks.
